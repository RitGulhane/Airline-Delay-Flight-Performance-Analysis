# Airline Delay & Flight Performance Analysis

## Project Overview
This project analyzes airline operations data using SQL and Power BI to identify flight delays, cancellation trends, airline performance, and operational efficiency.

## Tools Used
- SQL
- Power BI
- Data Visualization
- Data Analysis

## Key KPIs
- Total Flights
- Delayed Flights
- Cancellation Rate
- Average Delay Time
- Airline Performance Metrics

## Analysis Performed
- Flight Delay Analysis
- Cancellation Trend Analysis
- Airline-wise Performance
- Route Performance Analysis
- Operational Efficiency Insights
